This page reads your raw Last.fm export straight from lastfm_data.json, which needs to sit in the same folder as this HTML file. To update the report, just drop in a fresh export renamed to that exact filename.

Most browsers block a page opened by double-click (a file:// URL) from fetching another local file. Run a tiny local server from that folder instead, e.g.:

python3 -m http.server 8000

then open http://localhost:8000/listening_report.html in your browser.
